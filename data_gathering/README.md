# Download Matrices Script

This folder contains a script that allows you to download matrices fitting specific criteria from [SuiteSparse Matrix Collection](https://sparse.tamu.edu/). Below are the instructions to guide you through the process of adjusting the search query and running the script.

## Overview

The script `download_matrix.py` allows you to download matrices based on a set of customizable criteria. You can adjust the search query to suit your needs. Once the query is configured, you can execute the script to download the matrices that match your defined parameters.

## Usage

Run the Script

```
python3 download_matrix.py
```
